# 💰 Dashboard Financeiro

Dashboard interativo para controle de receitas e despesas mensais.

## 📁 Arquivos

| Arquivo | Descrição |
|---------|-----------|
| `dashboard_financeiro.html` | Dashboard visual interativo com gráficos |
| `controle_receitas_despesas.xlsx` | Planilha Excel com fórmulas automáticas |
| `Financeiro_Dashboard.md` | Nota do Obsidian com resumo e tabelas |

## 🎯 Metas

- **Meta semanal:** R$ 2.000,00 / semana
- **Meta mensal:** R$ 8.000,00 / mês
- **Total despesas fixas:** R$ 6.790,00 / mês

## 🚀 Como usar o Dashboard

1. Baixe o arquivo `dashboard_financeiro.html`
2. Abra no navegador (duplo clique)
3. Use o formulário para lançar receitas por semana
4. Os dados ficam salvos no navegador (localStorage)
